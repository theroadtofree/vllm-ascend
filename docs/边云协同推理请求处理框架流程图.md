## 四、单次 Step 请求处理完整流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant API as API Server
    participant EC as Edge EngineCoreProc
    participant Sch as Edge Scheduler
    participant EXE as Edge Executor
    participant EW as Edge Worker
    participant CW as Cloud Worker

    Client->>API: POST /v1/completions
    API->>EC: ZMQ: ADD request
    EC->>Sch: add_request()
    Sch->>Sch: 加入 waiting/running 队列

    loop 每轮 step
        EC->>Sch: schedule()
        Sch->>Sch: 分配 KV Cache<br/>计算 token budget<br/>生成 SchedulerOutput
        EC->>EXE: execute_model(SchedulerOutput)
        EXE->>EW: MQ RPC: execute_model

        Note over EW: Edge 执行 Head 部分
        EW->>EW: model_runner.execute_model()<br/>segment_a (Head)<br/>生成 IntermediateTensors

        alt forward_pass 且 hidden state 需要传递
            EW->>EW: get_pp_group().isend_tensor_dict()<br/>异步发送 hidden state
            EW->>CW: PP Comm: hidden state 传输

            Note over CW: Cloud 执行 Layers
            CW->>CW: edge_cloud_broadcast_recv()<br/>接收 hidden state
            CW->>CW: model_runner.execute_model()<br/>segment_c (Layers)<br/>生成输出 hidden state
            CW->>CW: get_pp_group().isend_tensor_dict()<br/>异步发送回 Edge
            CW->>EW: PP Comm: hidden state 回传

            Note over EW: Edge 执行 Tail 部分
            EW->>EW: edge_cloud_broadcast_recv()<br/>接收 Cloud 返回的 hidden state
            EW->>EW: model_runner.execute_model()<br/>segment_e (Tail)<br/>生成 logits
        end

        EW->>EW: sample_tokens()<br/>采样生成 token
        EW->>EXE: 返回 ModelRunnerOutput
        EXE->>EC: future.result()

        EC->>Sch: update_from_output()
        Sch->>Sch: 更新请求状态<br/>检查 stop 条件
        EC->>API: ZMQ: EngineCoreOutputs
        API->>Client: 流式/完整返回 token
    end
```

## 九、执行阶段对比

### Prefill 阶段

```
Edge (Head)          Cloud (Layers)          Edge (Tail)
  |                        |                       |
  |-- segment_a ---------> |                       |
  |   (Embedding+Head)     |                       |
  |                        |-- segment_c --------> |
  |   isend_tensor_dict    |   (中间层计算)         |   edge_cloud_broadcast_recv
  |                        |                       |
  |<-- irecv_tensor_dict --|                       |
  |                        |   isend_tensor_dict   |
  |-- segment_e ---------------------------------> |
  |                        |                       |   (Tail+LM Head)
  |                        |                       |-- compute_logits
  |                        |                       |-- sample_tokens
```

### Decode 阶段

```
流程与 Prefill 相同，但输入为单 token：
Edge Head (1 token) → Cloud Layers → Edge Tail → 采样 1 token
```
